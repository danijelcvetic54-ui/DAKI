# DAKI – Website

## Dateien
- `index.html` – Website-Inhalt
- `style.css` – Design, Farben und Animationen
- `script.js` – Discord-/Social-Links, Menü und Musikplayer
- `music.mp3` – deine eigene MP3-Datei (nicht in diesem ZIP enthalten)

## Musik aktivieren
1. Kopiere deine eigene MP3-Datei in denselben Ordner wie `index.html`.
2. Benenne sie exakt `music.mp3`.
3. Lade `music.mp3` auch in dein GitHub-Repository hoch.
4. Die Musik startet erst nach Klick auf „PLAY MUSIC“, weil Browser Autoplay normalerweise blockieren.

Bitte nutze nur Musik, die du verwenden darfst.

## Twitch und TikTok eintragen
Öffne `script.js` mit Editor/Notepad und ändere oben:
- `twitch: ""` zu deinem Twitch-Kanalnamen (ohne URL)
- `tiktok: ""` zu deinem TikTok-Namen (ohne @)

Speichern und die geänderte `script.js` erneut zu GitHub hochladen.

## Kostenlos mit GitHub Pages veröffentlichen
Im Repository: Settings → Pages → Build and deployment → Deploy from a branch → Branch `main`, Ordner `/ (root)` → Save. Warte, bis GitHub den Link anzeigt.
